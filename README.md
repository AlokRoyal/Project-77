# Space Explorer App (Project 77)

An Expo and React Native app organized around a four-screen space exploration flow: Home, Star Map, Daily Picture, and Spacecraft. `App.js` connects the screens with a React Navigation stack.

## Stack

- React 16.13
- React Native with Expo SDK 42
- React Navigation 5
- React Native Web

## Setup and run

Install dependencies with `npm install`, then run:

```bash
npm start
```

Use `npm run android`, `npm run ios`, or `npm run web` for a target platform. Native runs may require an emulator or device. Screen components are in `screens/` and app configuration is in `app.json`.

## Notes

Both `package-lock.json` and `yarn.lock` are present. Choose one package manager for reproducible installs.
